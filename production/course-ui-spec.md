# Public course interface

The course follows the current TFIS site's Atkinson Hyperlegible body/headings, JetBrains Mono controls, white/black/gray theme tokens and #c8511e accent. It retains the site's accessible dark/light treatment. This is a course for executives completing a sequence, so the primary structure is a lesson reader with seven numbered steps, not a marketing card grid.

Use a short course introduction beside the actual Board question. Keep the free-course/Plus distinction and setup requirements visible before Start. On desktop, a sticky lesson index accompanies a readable lesson column; on mobile it becomes an ordinary compact index above the lesson. The reader can choose a lesson, copy its prompt, reveal a checkpoint and record local completion. Essential text and links remain available without JavaScript.

All lesson text, prompts, source ZIP, glossary, control card, example brief and dashboard mirror are served by the public route. Links to privately owned native Sites/Pages are supplemental and explicitly labeled; no required public learning path relies on them. No enrollment, payment, messaging or learner database is added.

During production the page states that recordings and completion-time validation are pending and carries noindex. Do not replace a missing recording with a nonfunctional play button or imply a transcript was transcribed from a recording. Build the text lesson now; add real videos and matching captions when available.

The actual class materials remain authoritative in course-content. A deterministic build script compiles the workbook and prompts and copies verified downloads into delivery/public/pivot-2026 for isolated TFIS integration. It must not modify the unrelated dirty TFIS checkout.
