## Manual accessibility checks

Producer follow-up on 15 November verified course 320px reflow, 200% browser zoom, skip-link navigation, native rubric keyboard selection and dashboard filter/range/table keyboard use. A narrow demo-card overflow was fixed and retested in version 3. See `qa/responsive-keyboard-review.md` in the repository. The blank checklist below remains for the facilitator's own setup and actual assistive-technology review; these observations do not establish screen-reader announcements or full-clip listening.

- [ ] Tab reaches the skip link; Enter moves to main content.
- [ ] Keyboard can navigate lessons, play/pause video, copy prompts and open/close checkpoint and recovery disclosures.
- [ ] Focus remains visible and logical; no keyboard trap occurs.
- [ ] Native rubric selectors can choose and change a score by keyboard; status is announced after a complete score set.
- [ ] Screen-reader headings, controls, status messages, disclosures and tables have meaningful names and reading order.
- [ ] Text zoom and narrow reflow preserve controls and reading order without overlapping text.
- [ ] Captions remain legible at 390px and 1280px; transcript and full-screen video are available.
- [ ] Dashboard filters, scenario range and evidence tables work with keyboard and screen reader.
- [ ] Light and dark themes preserve visible text and focus contrast.
